# Дизайн Фектори: сайт + Telegram-бот

- `bot/` — бот-помощник (aiogram 3, hy/ru/en). Отвечает на простые вопросы (адрес, часы, как прислать файл, оплата...), принимает файл или фото и сам задаёт вопросы
  (формат, цвет, бумага, размер, тираж, срок, имя, телефон). Заявка уходит сотрудникам ТОЛЬКО когда заполнена полностью.
  14 услуг: ксерокопия, печать документов, сканирование, печать фото, фото на документы, плакаты, визитки/листовки/буклеты, наклейки и плоттерная резка,
  лазерная резка и гравировка, переплёт/ламинирование, дизайн, ретушь, мерч, другое + «вопрос менеджеру».
- `site/` — одностраничный сайт (hy/ru/en), кнопки услуг открывают бота сразу на нужных вопросах. `python tools/export_services.py` обновляет список услуг на сайте из бота.
- `shop.json` — адрес, телефон, часы: править здесь (бот и тексты берут отсюда). Пункты из `confirm` подтвердить у магазина.

## Запуск
1. `.env` (по образцу `.env.example`): BOT_TOKEN из @BotFather, OWNER_ID — ваш Telegram id.
2. `start_bot.bat` или `python -m bot.main`.
3. Заявки приходят в личку владельца; чтобы они шли в рабочую группу: добавить бота в группу и в ней отправить `/setstaff` (команда только для OWNER_ID).
4. Сотрудникам в чате доступны кнопки «Взял в работу / Готово / Спам» и `/orders`; при «Готово» клиент получает сообщение о готовности заказа.

Тесты: `python -m pytest tests` (61 тест, сеть Telegram подменена).
Армянский текст — черновик, нужна вычитка носителем. Цены бот не называет: их называет менеджер.
